# Changelog

All notable changes to this project are documented in this file.

## [1.0.0] - 2026-06-02

### Added

- Complete transformation from static HTML to React + TypeScript + Vite architecture.
- New product identity: EchoVerse, a Voice AI storytelling and podcast studio app.
- Unlimited voice generation workflow with long-form text support.
- Emotion Engine with 10 emotion modes and intensity control.
- Multi-character story mode with per-character voice, emotion, and style.
- Podcast studio with intro, episode script, outro, and optional background mode.
- Advanced audio controls for pitch, speed, volume, intensity, and pause timing.
- Real-time preview pipeline using Web Speech API.
- WAV export plus browser-dependent MP3 export path.
- Local project workspace (save/load/delete/clear) via browser storage.
- Premium responsive black-and-white UI with waveform animations.
- GitHub-ready documentation: README, LICENSE, CONTRIBUTING.
